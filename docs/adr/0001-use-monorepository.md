# ADR 0001 — Использовать monorepository

## Context

Два разработчика будут вести frontend и backend одной платформы. Нужны общие
типы/клиент, единый CI и согласованные инженерные стандарты без публикации
внутренних пакетов в npm.

## Decision

Хранить web, API и общие пакеты в одном репозитории `platform` на базе
pnpm workspace + Turborepo.

## Consequences

- Плюсы: единый review, общие конфиги, атомарные изменения контрактов.
- Минусы: выше сложность корневых скриптов и CI cache.
- Ограничение M0: не создаём `packages/ui`, `apps/worker` и лишние сервисы.
