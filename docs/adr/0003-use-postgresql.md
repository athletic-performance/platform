# ADR 0003 — Использовать PostgreSQL

## Context

Платформе нужны реляционные связи, ограничения целостности, история результатов
и транзакции вокруг доступов и тренировочных сессий.

## Decision

PostgreSQL — единый source of truth. Доступ из API через Prisma ORM.
На M0 создаётся только техническая миграция foundation без продуктовых таблиц.

## Consequences

- Плюсы: зрелая транзакционная модель, управляемые миграции, простой локальный запуск.
- Минусы: продуктовая схема должна проектироваться отдельно после freeze требований.
- Не вводим дополнительные брокеры/хранилища до явной потребности.
